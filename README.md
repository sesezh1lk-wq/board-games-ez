# ez board game

Назовите настолки, которые вам уже зашли. Подберём похожие: по вкусу, числу игроков, времени партии и сложности.

Открыли, отметили любимые, получили список. Можно оставить только короткие партии, лёгкие правила или компанию на четверых. У каждой игры — коротко, чем она хороша и где обычно скучают между ходами.
